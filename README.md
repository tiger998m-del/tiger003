# tiger003

مدونة باللغة العربية

قالب Blogger احترافي (عربي/RTL) جاهز للنشر + صفحات AdSense الأساسية + قالب مقالات منظم بعناوين H2.
راجع **[GUIDE.md](GUIDE.md)** لخطوات التركيب الكاملة وقائمة تحقق قبول AdSense.

## محتويات المستودع
- `theme/tiger003-theme.xml` — قالب Blogger كامل (نظيف، متجاوب، سريع، SEO، بدون إعلانات منبثقة)
- `pages/` — محتوى صفحات من نحن / تواصل معنا / سياسة الخصوصية / إخلاء المسؤولية الجاهزة للصق في Blogger
- `post-template/post-template.html` — قالب كتابة مقالة منظمة (مقدمة/محتوى/أسئلة شائعة/خاتمة) بعناوين H2 + Schema FAQ
